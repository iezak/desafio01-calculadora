# Desafio 01 - Calculadora React

Projeto desenvolvido para o desafio da Formacao React Developer da DIO.

## Sobre o projeto

Esta aplicacao e uma calculadora simples feita com React. Ela permite realizar operacoes basicas de soma, subtracao, multiplicacao e divisao, alem de trabalhar com numeros decimais.

## Funcionalidades

- Adicao, subtracao, multiplicacao e divisao
- Entrada de numeros decimais
- Correcao visual de resultados decimais, como `0.4 + 0.2`
- Botao `AC` para limpar a calculadora
- Repeticao da ultima operacao ao pressionar `=` novamente

## Tecnologias utilizadas

- React
- JavaScript
- Styled Components
- Create React App

## Como executar

Instale as dependencias:

```bash
npm install
```

Execute o projeto:

```bash
npm start
```

Acesse no navegador:

```txt
http://localhost:3000
```
